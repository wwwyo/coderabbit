# coderabbit

[Central configuration](https://docs.coderabbit.ai/configuration/central-configuration) for CodeRabbit. The `.coderabbit.yaml` in this repository applies to every repository in this account that doesn't have its own config file.

- `reviews.auto_review.drafts: true` — review draft PRs automatically (skipped by default)

CodeRabbit must be installed on this repository for the config to be read.
